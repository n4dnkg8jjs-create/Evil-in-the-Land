The two connection libraries the multiplayer uses, served with the game so that it does not depend on a CDN:

  peerjs.min.js   PeerJS 1.5.4    MIT licence   https://github.com/peers/peerjs
  mqtt.min.js     MQTT.js 5.10.1  MIT licence   https://github.com/mqttjs/MQTT.js

Unmodified copies of the packages' dist files (npm: peerjs@1.5.4, mqtt@5.10.1).
